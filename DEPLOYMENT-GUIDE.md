# PART 1: Set up Supabase (15 min)

## 1.1 Create Supabase account

1. Go to **https://supabase.com**
2. Click "Start your project" → "Sign up with Google"
3. **TIP:** Use a separate Google account from your main MintyDeals one. This isolates the project.

## 1.2 Create new project

1. Click **"New Project"**
2. Fill in:
   - **Organization:** Create new → name it `mintydeals-tools`
   - **Project name:** `mintydeals-tools`
   - **Database password:** Click "Generate a password" → **COPY IT to your password manager NOW**
   - **Region:** **Asia South (Mumbai)** ← critical for India users
   - **Plan:** Free
3. Click **"Create new project"** → wait ~2 minutes for provisioning

## 1.3 Copy your credentials

Once project is ready:
1. Left sidebar → **Settings** (gear icon at bottom) → **API**
2. Copy these into a notes file:

```
SUPABASE_URL = https://YOUR_PROJECT_ID.supabase.co
ANON_KEY = eyJhbGciOiJIUzI1NiIs.....(long string)
SERVICE_ROLE_KEY = eyJhbGciOiJIUzI1NiIs.....(KEEP SECRET)
PROJECT_REF = YOUR_PROJECT_ID (the abcdefg part of the URL)
```

⚠️ **NEVER share the SERVICE_ROLE_KEY publicly.** It bypasses all security.

## 1.4 Create database tables

1. Left sidebar → **SQL Editor** → **New query**
2. Paste this entire block and click **Run** (bottom right, or Ctrl+Enter):

```sql
-- ============================================
-- Table 1: Lottery results
-- ============================================
create table lottery_results (
  id bigint generated by default as identity primary key,
  lottery text not null,
  draw_date date not null,
  draw_code text,
  draw_name text,
  main_numbers integer[],
  bonus_number integer,
  first_prize_ticket text,
  first_prize_location text,
  second_prize_ticket text,
  second_prize_location text,
  third_prize_ticket text,
  third_prize_location text,
  consolation_tickets text[],
  fourth_prize_tickets text[],
  prize_4_digit jsonb,
  next_draw_date date,
  next_draw_code text,
  next_jackpot text,
  source_url text,
  created_at timestamptz default now(),
  unique(lottery, draw_date)
);

create index idx_lottery_date on lottery_results(lottery, draw_date desc);

alter table lottery_results enable row level security;
create policy "Public read lottery results" 
  on lottery_results for select 
  using (true);


-- ============================================
-- Table 2: Scan analytics
-- ============================================
create table scan_logs (
  id bigint generated by default as identity primary key,
  lottery text not null,
  confidence text,
  is_win boolean,
  prize_tier text,
  ip_country text,
  user_agent text,
  created_at timestamptz default now()
);

create index idx_scans_created on scan_logs(created_at desc);
create index idx_scans_lottery on scan_logs(lottery);

alter table scan_logs enable row level security;


-- ============================================
-- Table 3: Email subscribers
-- ============================================
create table subscribers (
  id bigint generated by default as identity primary key,
  email text not null unique,
  lotteries text[] not null default '{}',
  is_active boolean default true,
  unsubscribe_token text default gen_random_uuid()::text,
  created_at timestamptz default now()
);

create index idx_subscribers_email on subscribers(email);

alter table subscribers enable row level security;
create policy "Public can subscribe" 
  on subscribers for insert 
  with check (true);
```

You should see "**Success. No rows returned**" — that's correct.

3. **Verify:** Left sidebar → **Table Editor** → you should see 3 tables.

## 1.5 Get a Gemini API key

1. Open new tab → **https://aistudio.google.com/apikey**
2. Sign in with Google
3. Click **"Create API key"** → "Create API key in new project"
4. Copy the key (starts with `AIzaSy...`) — save it in your notes

## 1.6 Install Supabase CLI on your computer

**On Windows:**
1. Install Node.js if you don't have it: https://nodejs.org (download LTS version)
2. Open **PowerShell** (search "PowerShell" in Start menu)
3. Run:
```powershell
npm install -g supabase
```

**On Mac:**
```bash
brew install supabase/tap/supabase
```

**Verify:**
```
supabase --version
```
Should show something like `1.x.x`

## 1.7 Deploy the edge function

1. Open the folder where you saved `mintydeals-tools/`
2. In PowerShell/Terminal, navigate to that folder:
```bash
cd path/to/mintydeals-tools
```

3. Login to Supabase:
```bash
supabase login
```
This opens browser → click "Authorize" → copy the token → paste in terminal

4. Initialize Supabase in this folder:
```bash
supabase init
```
(Press Enter to accept defaults)

5. Link to your project:
```bash
supabase link --project-ref YOUR_PROJECT_REF
```
Replace `YOUR_PROJECT_REF` with the value from step 1.3. Press Enter when it asks for the database password (the one you saved in 1.2).

6. Set the Gemini API key as a secret:
```bash
supabase secrets set GEMINI_API_KEY=AIzaSy_paste_your_key_here
```

7. Move the edge function into the right folder:
```bash
mkdir -p supabase/functions/scan-ticket
```
Then copy `backend/scan-ticket.ts` into `supabase/functions/scan-ticket/index.ts`

**Windows:**
```powershell
Copy-Item backend\scan-ticket.ts supabase\functions\scan-ticket\index.ts
```

**Mac/Linux:**
```bash
cp backend/scan-ticket.ts supabase/functions/scan-ticket/index.ts
```

8. Deploy:
```bash
supabase functions deploy scan-ticket --no-verify-jwt
```

You should see: `Deployed Function scan-ticket on project YOUR_PROJECT_REF`

9. Your function is now live at:
```
https://YOUR_PROJECT_REF.supabase.co/functions/v1/scan-ticket
```

✅ **Part 1 complete.** Save these in your notes:
- SUPABASE_URL
- ANON_KEY
- Function URL

# PART 3: Deploy to Cloudflare Pages (15 min)

## 3.1 Create Cloudflare account

1. Go to **https://dash.cloudflare.com/sign-up**
2. Sign up with email + password
3. Verify your email
4. **Skip** the "Add a site" step — you don't need to move DNS to Cloudflare

## 3.2 Create a Pages project

1. From Cloudflare dashboard, left sidebar → **Workers & Pages**
2. Click **Create application** → **Pages** tab → **Upload assets**
3. Project name: `mintydeals-tools`
4. Production branch: `main` (default is fine)
5. Click **Create project**

## 3.3 Upload your files

1. You'll see a drag-drop area. **Drag the entire `mintydeals-tools` folder into it.**
2. ⚠️ Important: Drop the **contents** of the folder, not the folder itself. Your structure should be:
   ```
   /index.html
   /sitemap.xml
   /robots.txt
   /scanner/index.html
   /kerala-lottery-result-today/index.html
   ```
3. Click **Deploy site**
4. Wait ~30 seconds. You'll get a URL like:
   ```
   https://mintydeals-tools.pages.dev
   ```

## 3.4 Test the temporary URL

Visit `https://mintydeals-tools.pages.dev` — you should see your main hub page.

Visit `https://mintydeals-tools.pages.dev/scanner/` — you should see the scanner.

Visit `https://mintydeals-tools.pages.dev/kerala-lottery-result-today/` — Kerala page.

# PART 4: Connect tools.mintydeals.com (10 min)

## 4.1 Add custom domain in Cloudflare Pages

1. In your Pages project → top tabs → **Custom domains**
2. Click **Set up a custom domain**
3. Type: `tools.mintydeals.com`
4. Click **Continue**
5. Cloudflare shows you the **CNAME record value** to add. It looks like:
   ```
   Type: CNAME
   Name: tools
   Target: mintydeals-tools.pages.dev
   ```
6. **Keep this Cloudflare page open** — you'll come back to it after adding the DNS record.

## 4.2 Add CNAME record in Hostinger

1. New tab → **https://hpanel.hostinger.com**
2. Login → click **Domains** in left sidebar
3. Find `mintydeals.com` → click **Manage**
4. In the domain dashboard, look for **DNS / Nameservers** in the left sidebar (might be under "Domain")
5. Click **DNS Zone Editor** or **Manage DNS records**
6. Scroll to the bottom → **Add new record** section:

   | Field | Value |
   |---|---|
   | **Type** | `CNAME` |
   | **Name** | `tools` |
   | **Points to / Target** | `mintydeals-tools.pages.dev` |
   | **TTL** | `3600` (or "Auto") |

7. Click **Add Record** or **Save**

## 4.3 Verify in Cloudflare

1. Go back to your Cloudflare Pages → **Custom domains** tab
2. Click **Verify** or just wait
3. Cloudflare will check the DNS:
   - Initial check: "Setting up custom domain..."
   - After DNS propagates (5–30 min): "Active" with a green checkmark
   - SSL certificate is auto-issued (also takes 5–10 min)

## 4.4 Test your live domain

After DNS propagates (use **https://dnschecker.org** to check), visit:

- `https://tools.mintydeals.com` ← Main hub
- `https://tools.mintydeals.com/scanner/` ← AI scanner
- `https://tools.mintydeals.com/kerala-lottery-result-today/` ← Kerala results

✅ **You're live.**

# PART 5: Set up SEO (15 min)

## 5.1 Google Search Console

1. Go to **https://search.google.com/search-console**
2. Sign in with Google
3. Click **Add property**
4. Choose **URL prefix** (not Domain — easier)
5. Enter: `https://tools.mintydeals.com`
6. Click **Continue**
7. **Verification:** Choose **HTML tag** method
8. Copy the meta tag (looks like `<meta name="google-site-verification" content="abc123...">`)
9. Open `index.html` → paste the meta tag inside `<head>` right after the `<title>` tag
10. Save and re-upload to Cloudflare Pages (drag the file again, it replaces the old one)
11. Wait 2-3 minutes for the new version to deploy
12. Go back to Search Console → click **Verify**
13. ✅ Property verified

## 5.2 Submit your sitemap

1. In Search Console → left sidebar → **Sitemaps**
2. Add new sitemap → type: `sitemap.xml`
3. Click **Submit**
4. Status should change to "Success" within minutes

## 5.3 Request indexing for the main pages

For each of these URLs, do the following:
- `https://tools.mintydeals.com/`
- `https://tools.mintydeals.com/scanner/`
- `https://tools.mintydeals.com/kerala-lottery-result-today/`

1. In Search Console, top bar → **URL Inspection**
2. Paste the URL
3. Click **Request indexing**
4. Wait ~10 seconds → "Indexing requested" ✅

1. Go to **https://analytics.google.com**
2. Create account → property name: "MintyDeals Tools"
3. Country: India, Timezone: India Standard Time, Currency: INR
4. Get your **Measurement ID** (format: `G-XXXXXXXXXX`)
5. Add this code right before the closing `</head>` tag in all 3 HTML files:


Replace `G-XXXXXXXXXX` with your real Measurement ID. Re-upload to Cloudflare.

# 🆘 Troubleshooting

## "DNS not propagating"
- Wait up to 24 hours (usually 30 min)
- Check status: https://dnschecker.org → paste `tools.mintydeals.com` → look for green checkmarks

## "Scanner returns error: 'Failed to fetch'"
- Open browser console (F12) → check the Network tab
- Verify SUPABASE_URL and SUPABASE_ANON_KEY are correctly set
- Verify the edge function deployed: `supabase functions list`
- Re-deploy: `supabase functions deploy scan-ticket --no-verify-jwt`

## "AI vision service error"
- Verify Gemini API key is set: `supabase secrets list` (should show GEMINI_API_KEY)
- Check Gemini quota: https://aistudio.google.com/apikey (free tier = 1500/day)
- Re-set the key if expired: `supabase secrets set GEMINI_API_KEY=new_key`

## "Cloudflare shows 404 on subpages"
- Check folder structure: scanner files must be at `/scanner/index.html` (NOT `/scanner.html`)
- Re-upload preserving folder structure

## "Hostinger DNS panel doesn't show CNAME option"
- Some Hostinger plans use a different panel — look for "Manage DNS Zone" or "Advanced DNS"
- Contact Hostinger live chat — they're fast: bottom-right chat icon
